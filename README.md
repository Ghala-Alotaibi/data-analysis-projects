# data-analysis-projects
A portfolio of data analysis projects and Jupyter notebooks showcasing data cleaning, exploratory data analysis (EDA), visualization, statistical insights, and machine learning techniques using Python.

## Projects

### 🚲 Bike Sales Analysis

Analysis of customer purchasing behavior using a bike sales dataset.

**Objectives**
- Clean and prepare the dataset
- Explore customer demographics
- Analyze bike purchasing behavior
- Identify factors associated with bike purchases
- Visualize key insights

**Tools**
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

**Dataset**
1,000 customer records containing information such as:
- Age
- Income
- Gender
- Occupation
- Region
- Commute distance
- Cars owned
- Bike purchase status
